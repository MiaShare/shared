PLAT-33 — Resend-Tools Prompt Backfill

Add the “Resending contracts and disclosures” guidance to the existing AI Assistant (School) prompt in production. Dry-run first, then full run.

command: backfill:ai-assistant-school-prompt-for-resend-tools idempotent prod data write

i What this is

PLAT-33 taught Mia to resend contracts & disclosure copies — the “Resending contracts and disclosures” guidance block (contact-search → resend-contract-draft / resend-disclosure-copy-draft, confirm card, disambiguation, 24-hour budget).

Fresh databases get that text from the seeder. Existing rows (production) get it from this one-time backfill command. Production never ran it, so prod’s Mia is missing the section.

The command finds every ai-assistant-school prompt row that lacks the ### Resending contracts and disclosures marker and inserts the block right before <user_context>. Rows that already have it are skipped — safe to re-run.

!

Environment — read before running

This is a production data write. Two things to get right:

  • The full run must point at the prod PRIMARY (writable) DB. Run it on the prod app host (Forge / Horizon box) via your normal deploy path — not from a local workspace.
  • A workspace pointed at the read-only replica: the --dry-run is safe (writes nothing; replica reflects prod state, so the preview count is accurate). The full run will fail against the replica. Do not repoint .env to primary just to run it — run it on prod.

1 Dry-run — preview, no writes READ-ONLY

On prod (or against the replica for a safe preview):

php -d memory_limit=512M artisan backfill:ai-assistant-school-prompt-for-resend-tools --dry-run

Expected output (prod has 1 global row missing it, 0 institution overrides):

Would patch prompt #<id> (global).
Done. Would update: 1. Already had marker: 0. Total examined: 1.
  • Would update: 1 → correct — exactly the global school prompt.
  • Already had marker: N → those rows already have the section (skipped).
  • If Would update is higher than expected, stop and inspect — each institution override would also be patched.

2 Full run — writes, on prod primary WRITES

After the dry-run looks right:

php -d memory_limit=512M artisan backfill:ai-assistant-school-prompt-for-resend-tools

Expected:

Done. Updated: 1. Already had marker: 0. Total examined: 1.

Re-runnable and safe: running it again does nothing (reports Already had marker: 1, Updated: 0).

3 Verify READ-ONLY

php -d memory_limit=512M artisan backfill:ai-assistant-school-prompt-for-resend-tools --dry-run

Should now report Would update: 0, Already had marker: 1. That’s the converged state.
